# Train Smart PWA

Aplicativo mobile-first para planejamento de treino de 24 semanas.

## Recursos atuais
- Objetivos: Definição, Hipertrofia, Força, Resistência e Condicionamento.
- Fases automáticas por semana.
- Ficha muda automaticamente conforme a fase.
- Registro simplificado: somente a carga utilizada.
- Histórico de cargas.
- Peso e cintura.
- PWA com manifest e service worker para uso offline.

## GitHub Pages
Para publicar:
1. Abra **Settings > Pages**.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione **main** e **/(root)**.
4. Salve e aguarde o endereço do GitHub Pages aparecer.

Depois abra o endereço no Chrome do Android e use **Instalar app** / **Adicionar à tela inicial**.
